# COMP4010/5120 - Data Visualization - Spring 2026
This course teaches techniques and algorithms for creating effective visualizations of large datasets and their analytics, based on principles from graphic design, visual art, perceptual psychology and cognitive science. In addition to participating in class discussions, students will have to complete several short data analysis and visualization design assignments as well as a final project. 

## Prerequisites

- Working knowledge of Python (Pandas and basic plotting are a plus)
- Familiarity with Jupyter notebooks
- A GitHub account for submitting assignments

## Tools we will use

- Python 3.10+
- Pandas, NumPy
- Matplotlib, Seaborn, Plotly, Altair
- Python Shiny for interactive applications
- Optional: GeoPandas, PyDeck, Scikit-learn
